# Phase Overview

## Purpose

This file gives the high-level development roadmap across phases.

## Phase Strategy

Build in stages.

Preferred order:
- establish foundation
- stabilize one vertical slice
- document it
- then expand

Do not partially build many major systems at the same time unless the roadmap explicitly allows it.

## Program Shape

### Phase 1

Foundation validation:
- modular home screen
- scalable project structure
- initial documentation and rules

### Phase 2

Connected productivity foundation:
- notes
- reminders
- todo
- task
- calendar
- alarm and clock

### Later Phases

Possible later expansions:
- screen sharing
- gallery
- attachments
- voice assistant
- media
- sync

## Dependency Direction

Foundations should come before integrations.

Examples:
- notes foundation before reminder linking
- reminder engine before repeat rules
- storage strategy before attachment-heavy features
