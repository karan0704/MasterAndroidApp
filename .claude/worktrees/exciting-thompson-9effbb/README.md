# Master Android App

Master Android App is a React Native productivity platform designed to grow into a modular ecosystem instead of a single-purpose app.

The project is being documented for:
- low-context AI development
- scalable feature growth
- universal mobile UI behavior
- offline-first storage
- future Android, iOS, Windows, and Linux expansion

## Start Here

The canonical project documentation now lives in:

- [`src/docs/README.md`](src/docs/README.md)

Recommended reading order:

1. `src/docs/README.md`
2. `src/docs/project/*`
3. `src/docs/engineering/*`
4. `src/docs/ui/*`
5. `src/docs/roadmap/*`
6. `src/docs/features/<feature-name>/*`

## App Setup

```sh
npm install
npm start
```

Android:

```sh
npm run android
```

iOS:

```sh
bundle install
bundle exec pod install
npm run ios
```
