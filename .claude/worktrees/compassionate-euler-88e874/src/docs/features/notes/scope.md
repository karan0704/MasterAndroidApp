# Notes Scope

## Feature Goal

Build a notes system that is:
- useful locally first
- markdown-first
- scalable toward a connected productivity graph

## Current And Near-Term Scope

Early notes work includes:
- floating notes entry
- notes list
- note editor
- markdown file storage
- SQLite metadata

## Explicitly Out Of Scope For Early Notes

Until later phases, avoid assuming:
- attachments
- voice notes
- location-based reminders
- deep reminder linking
- complex sync
- rich media editing

## Scope Rule

Notes should be implemented in ordered slices, not by partially building every future idea.
