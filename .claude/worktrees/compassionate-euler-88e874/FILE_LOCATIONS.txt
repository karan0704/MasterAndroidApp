KEY RELATIONSHIPS
================================================================================

🔗 Frontend → Backend
   youtubeService.ts → http://localhost:3000/api/youtube/metadata
   youtubeService.ts → http://localhost:3000/api/youtube/download-url
   downloadService.ts → RNFS.downloadFile(url)

🔗 Frontend → Database
   downloadService.ts → SQLite youtube_downloads table
   useYoutubeDownloads.ts → Queries for UI updates

🔗 Frontend → Storage
   downloadService.ts → /Documents/youtube-downloads/
                      → /videos/, /audio/, /thumbnails/
