# Notes Roadmap

## Ordered Phases

1. Floating notes entry
2. Notes list
3. Note editor
4. Markdown storage
5. Metadata system
6. Checkpoints
7. Reminder linking
8. Attachments

## Build Direction

Finish the notes foundation before deep integrations.

## Notes As A Foundation Module

Notes is not just a text editor.
It is expected to become a hub for:
- reminders
- todo references
- calendar links
- attachments

That future growth must still preserve clear ownership and readable boundaries.
